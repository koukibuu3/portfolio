# コピー設計

2026-10-21 / v0.11

## 方針

人物・制作物・担当した仕事を具体的に示す。各セクションの目的を説明する文章、抽象的な宣言、重複する自己紹介は省く。技術用語は意味がある箇所で使い、未確認の技術・役割・成果は加えない。

Projectsは画像面と名前・短い概要で構成し、技術タグや追加の説明文は増やさない。

文体の調整に合わせ、見出し・カードの余白も縮める。等幅書体は職種、日付、技術名などのメタ情報に限定する。

## 経歴の要約

会社名・期間・職種・雇用区分・技術は残し、本文を担当内容へ絞る。SESの参画先を所属企業から独立させず、匿名案件も匿名のままとする。記事のタイトルや公開日はコピー調整の対象にしない。

「つくったもの、考えたこと、歩んできたこと。」は元の仕様のコンセプトとして保存する。画面の大きな宣伝文句としては使用しない。原文のプロフィールと経歴は[仕様書v1.0](requirements-v1.md)に残し、今回の表示文はその要約として扱う。

## 追加の削除指定

DM送信業務のシステム化、SESとしての参画を述べる前置き、開発プロセス・協働改善への関心、日常の課題や興味を起点とする個人開発の紹介文は表示しない。短縮版のプロフィール・経歴・Focusからも該当記述を削除する。会社名・在籍期間・担当した設計開発・技術一覧は維持する。

## Focusの情報量

Focusの見出し・本文は、ユーザーの再指定に従って仕様書v1.0の原文へ戻す。直前の2文への書き換えは採用しない。他セクションの簡潔化と削除指定は維持する。
